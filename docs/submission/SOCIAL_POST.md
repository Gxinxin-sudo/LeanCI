I built LeanCI for the Build with Paritok hackathon: a safer way to debug massive CI logs with
measured context compression.

The fixed formal path is FastAPI → Paritok Proxy → Paritok hosted GPU → DeepSeek V4 Flash. LeanCI
returns a strict root cause, log evidence, relevant files, a patch, and verification steps—without
executing user code or model suggestions.

In the frozen five-case benchmark, 2 rows actually compressed and averaged 85.53% Token savings;
3 were transparently retained as low-yield skips. Deterministic quality changed from 73/100 to
54/100, so the project publishes the tradeoff instead of claiming universal quality preservation.

Code, real Sample outputs, benchmark rows, and security model:
https://github.com/Gxinxin-sudo/LeanCI
